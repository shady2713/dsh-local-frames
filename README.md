# dsh-local-frames

DSH 插件：用户提供本地视频路径，插件按规则抽帧、做帧去重、逐帧按用户定义的对象打标签，并导出图片与 CSV。

- [需求与实施方案（唯一规格）](docs/LOCAL_VIDEO_PLUGIN_SPEC.md)
- [给云电脑 DSH 的开发提示词](PROMPT.md)

## 处理流程

1. 用户提交本地视频文件或目录；
2. `ffprobe` 读取时长，按设置的间隔计算抽帧时间点；
3. `ffmpeg` 取帧，按 64 位 dHash 做同任务跨视频帧去重；
4. 去重后的唯一帧逐帧调用视觉模型，只判断用户定义的对象是否出现、是否看得清；
5. 导出 `images/`、`labels.csv`、`sources.csv`、`README.txt`。

插件不访问网站、不下载、不检索，不判断视频是否航拍、是否真实、质量高低或水印；用户保证输入视频可用。插件对原视频只读，绝不删除、移动或改写原文件。
