# dsh-local-frames

DSH 插件：用户提供本地视频路径，插件按规则抽帧、做帧去重、逐帧按用户定义的对象打标签，并导出图片与 CSV。

## 处理流程

1. 用户提交本地视频文件或目录；
2. `ffprobe` 读取时长，按设置的间隔计算抽帧时间点；
3. `ffmpeg` 取帧，按 64 位 dHash 做同任务跨视频帧去重；
4. 去重后的唯一帧逐帧调用视觉模型，只判断用户定义的对象是否出现、是否看得清；
5. 导出 `images/`、`labels.csv`、`sources.csv`、`README.txt`、`stats.json`。

导出可以只选部分对象（`labels.csv` 只保留所选对象列），可写成 zip、按对象分目录（`images/<对象>/`），并生成 `stats.json` 统计报表；每次导出新建目录或 zip，不覆盖旧结果。已完成任务可反复导出，只复用已有帧与标签，不会重新抽帧或调用模型。统一页面「本地视频帧」包含环境/设置、对象、当前任务进度、任务列表和导出，并显示最近导出记录、提供「打开目录」和「复制路径」。

插件不访问网站、不下载、不检索，不判断视频是否航拍、是否真实、质量高低或水印；用户保证输入视频可用。插件对原视频只读，绝不删除、移动或改写原文件。
